# T05 고정 검사 10개 + 공통 사용 상한

이 문서는 AI A(Claude, 이 세션) 작업 시작 **전에** 고정되었으며, AI A/AI B 양쪽에 동일하게 적용된다.
어느 쪽도 이 문서 확정 이후 검사 삭제·완화·기대값 변경을 하지 않는다.

## 소재: 진앙 좌표를 인터랙티브 3D 지구본으로 표시

T04 결과물(`reum2kr/t04-earthquake-board`)의 작은 개선점 하나. 현재 실시간 조회 카드에 좌표값만 텍스트로 표시되던 것을,
드래그로 회전·휠로 확대/축소 가능한 3D 지구본 위 마커로 시각화한다.

## 공통 사용 상한

- **시간 상한**: 2시간 (AI A, AI B 각각)
- **요청·호출 수 상한**: 20회 (AI A, AI B 각각 — AI에게 보낸 메시지 수 기준)

## 고정 검사 10개

| ID | 입력 | 기대값 |
|---|---|---|
| T05-T01 | 배포된 페이지 로드 | ①카드 안에 3D 지구본 캔버스(WebGL)가 렌더링됨 |
| T05-T02 | 현재 최대 규모 지진의 위도/경도(geometry.coordinates) | 지구본 표면의 해당 좌표 위치에 진앙 마커가 정확히 표시됨 |
| T05-T03 | 마우스로 지구본을 좌우로 100px 드래그 | 드래그 방향에 따라 지구본이 회전함 |
| T05-T04 | 마우스 휠 위로 스크롤 | 지구본이 확대됨(카메라 거리 감소) |
| T05-T05 | 마우스 휠 아래로 스크롤 | 지구본이 축소됨(카메라 거리 증가) |
| T05-T06 | 휠을 50회 연속 확대 방향으로 스크롤 | 정해진 최소 거리 이하로는 더 확대되지 않음(경계값 클램프) |
| T05-T07 | 휠을 50회 연속 축소 방향으로 스크롤 | 정해진 최대 거리 이상으로는 더 축소되지 않음(경계값 클램프) |
| T05-T08 | 지구본 텍스처 로드를 강제로 실패시킴(네트워크 차단) | 페이지가 깨지지 않고 대체 안내(로딩 실패 표시)가 나타나며, 나머지 값(규모/단위 등)은 정상 표시 유지 |
| T05-T09 | 정상 조회 1회 실행 | daily-readings.json에 저장되는 필드가 기존 9개 그대로이며(추가 필드 없음), 값이 화면과 일치함 |
| T05-T10 | 브라우저 창 너비를 375px(모바일 폭)로 축소 | 지구본 캔버스가 카드 폭을 넘지 않고 반응형으로 줄어듦 |
