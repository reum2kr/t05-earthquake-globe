# T05 인수인계 문서 (AI A → AI B)

## 1. 목표
과제4 결과물(`reum2kr/t04-earthquake-board`)의 작은 개선점으로, 실시간 조회 카드의 진앙 좌표를
텍스트 대신 **드래그로 회전, 휠로 확대/축소 가능한 3D 지구본** 위 마커로 시각화한다.
고정 검사 10개(`docs/t05-fixed-tests.md`)를 전부 통과시키는 것이 완료 기준.

## 2. 현재 상태
- 배포 URL: https://reum2kr.github.io/t05-earthquake-globe/
- 저장소: https://github.com/reum2kr/t05-earthquake-globe
- Three.js(CDN, import map 방식)로 지구본 구현 완료
- `docs/t05-fixed-tests.md`에 고정한 검사 10개(T05-T01~T05-T10) **전부 육안 확인 완료**
  (브라우저 콘솔 에러/경고 0건, 지구본 렌더링·마커 위치·드래그 회전·휠 확대축소·경계 클램프·
  텍스처 실패 폴백·반응형 축소·스키마 미변경 전부 확인됨)
- 저장 스키마(`daily-readings.json`)는 T04와 동일한 9개 필드 그대로 유지, 좌표는 화면 표시 전용

## 3. 실행 명령
정적 사이트라 별도 빌드 과정 없음. 로컬 확인 시:
GitHub Pages 배포는 Settings → Pages (main 브랜치, /root)로 이미 켜져 있음.

## 5. 남은 문제
- 육안 확인만 했고, 자동화된 테스트 스크립트는 작성하지 않음(수동 재현 방식)
- 텍스처 이미지가 외부 CDN(threejs.org)에 의존 — 그 서버가 장애나면 T05-T08 폴백이 상시 발동하는 구조(기능상 안전하지만, 원한다면 자체 호스팅 이미지로 교체 검토 가능)
- 모바일 실기기(터치 드래그/핀치 줌)에서는 아직 미검증 — 데스크톱 브라우저 창 축소로만 반응형 확인함
